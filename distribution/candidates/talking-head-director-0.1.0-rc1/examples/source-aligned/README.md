# Source-aligned edit

This is the reusable form of a cut that is locked to a source recording.
`thd auto` is a different path. It drafts a plan from a transcript. It does
not build this edit.

## What it keeps

- The story is the segment list. Source order is not the edit order.
- Captions are the words that were aligned or synthesised, mapped through the
  edit list. The example's words are the fixture's own record.
- A waveform card is drawn only when the plan names at least two windows of
  the same source audio, with one pixels-per-second and one amplitude scale.
  The card says it is not a controlled measurement.
- The stage is the engine's cutting mat, ivory paper, and tape.
- A tracked mark is a colour centroid in the source frame, labelled from the
  plan. The example draws a red dot so the tracker has something to find.
- The diagram is labelled "simplified illustration · not to scale". Its words
  come from the plan.
- `preview` writes a short cut. `full` refuses to run until `approve` has been
  run on that same segment list.

## What it does not keep

No path on the author's machine. No transcript of a real video. No product
names. No finished film. The fixture is generated by `make_fixture.py`.

## Run

From the engine root, with the engine's virtualenv:

```bash
python3 examples/source-aligned/make_fixture.py
python3 scripts/aligned/render.py examples/source-aligned/plan.yaml preview 3
python3 scripts/aligned/render.py examples/source-aligned/plan.yaml approve
python3 scripts/aligned/render.py examples/source-aligned/plan.yaml full 3
```

Workers default to 3. If `scripts/thd` is not executable, run `bash scripts/thd`.

A shell script named espeak-ng that calls ffmpeg flite is not espeak-ng.
`make_fixture.py` refuses that stand-in. `thd doctor` warns about it.
The fixture's spoken line is not a person's voice.
